# Titanic Survivor Prediction 🚢

This project is a Machine Learning-based Titanic Survivor Prediction System that predicts whether a passenger would survive the Titanic disaster based on passenger details.

The model was trained using the famous Titanic dataset and saved using a `.pkl` pipeline file for prediction purposes.

## Project Overview

The project includes:

* Data preprocessing
* Feature engineering
* Model training
* Model evaluation
* Pipeline creation using Scikit-learn

The trained pipeline combines preprocessing and prediction into a single model for efficient predictions.

## File Descriptions

* **TitanicModels.ipynb**
  Jupyter Notebook containing data preprocessing, feature engineering, model training, evaluation, and prediction workflow.

* **titanic_svm_pipeline.pkl**
  Stores the trained Support Vector Machine (SVM) pipeline model used for survival prediction.

* **titanic.csv**
  Dataset used for training and testing the machine learning model.
